# KBO 투구 제구 성공 확률 예측

> LG Aimers 9기 · DACON · 97위 (1146.91)

투구 하나에 대해 공을 던지기 전까지 알 수 있는 정보만으로 제구 성공 확률을 예측함. 학습은 2019~2024 시즌 약 147만 구, 평가는 비공개 2025 시즌. 상수 0.5 기준 Brier Skill Score × 1e5 로 채점하고, 평가 데이터의 각 행은 서로 독립적으로 예측해야 함.

설계 근거와 전체 서술은 [프로젝트 노트](https://chb2066.github.io/projects/kbo-pitch-command/)에 있음.

## 점수 전이

오프라인 검증과 리더보드 점수 간 차이 존재. 오프라인 검증 내 점수 증가가 리더보드에 전이 되느냐 안되느냐를 기준으로 실험 진행

| 변경 종류 | 오프라인 → 리더보드 반영률 |
|---|---|
| 개별 칼럼 추가 (투수 × 좌우 같은 조합 피처) | 0% 또는 음수 |
| 구조·체제 보정 (제도 변화에 걸린 피처) | ~90% |
| 앙상블·보정 | ~90% |

## 실험 결과

**전이된 것**

| 시도 | 오프라인 | 리더보드 | 채택 |
|---|---:|---:|:---:|
| 경기유형 3범주 재코딩 (R / F_old / F_new) | 2023 +360 | +35 | O |
| 팀 단위 체제 지시자 | +33.7 | +38.1 | O |
| 잔차 보정 (투수·상황별 동결표) | - | +35 | O |
| 5클래스 분류 블렌드 + 클리핑 + 시드 앙상블 | - | +12.8 | O |
| 평균 보정 (정규리그·퓨처스 분리 외삽) | RMSE 0.01748 → 0.01213 | - | O |

**전이되지 않은 것**

| 시도 | 오프라인 | 리더보드 | 채택 |
|---|---:|---:|:---:|
| 투수·타자 매치업 피처 | +33 | +5 | X |
| 볼카운트별 조건부 통계 16개 | +41.5 | −6 | X |
| 조건부 통계 28개 + 5클래스 분류 | +90.6 | −6 | X |

리더보드 점수 차이의 표준오차가 부트스트랩으로 약 13점이라, −6 은 해로웠다기보다 효과가 없었다고 봐야함. 다만 두 번 연속 같은 자리에 떨어졌으므로 +40~+90 규모의 효과는 없다고 판단함.

**실패 실험 요소**

| 시도 | 결과 | 이유 |
|---|---|---|
| 모델 계열 교체 (XGBoost, DART, ExtraTrees) | 기여 0 | 예측 간 상관 0.94~0.98, 다양성 없음 |
| AutoGluon | 747.5 (기존 913.8) | 기준선 미달 |
| 시간 기반 스태킹 | −73 ~ −228 | 시즌 경계를 못 넘음 |
| 최근 시즌 가중 7가지 | 전부 음수 | 동일 |
| MARCEL 투영 / 경험적 베이즈 / 학습된 투영 | +1.7 / −5.2 / −151.9 | 기존 피처가 실력 추정을 이미 담고 있었음 |
| TrackMan 투구별 물리량 | 학습 데이터에서 +423.3 | 가치가 전부 그 투구의 편차에서 나오는데, 던지기 전에는 알 수 없음 |
| 볼카운트별 시즌 내 갱신 | +43.9 ~ +95.6 | 평가 데이터의 다른 행을 누적해야 만들 수 있어 규정 위반 |


## 최종 구성

```
입력      그 투구 이전에 알 수 있는 정보만 사용
          기본 피처 64개 (공식 누적 기록·경기 상황 47개, 행 단위 복원 이번 시즌 기록 17개)
          경기유형 재코딩 (정규리그 / 2022년까지 퓨처스 / 2023년 이후 퓨처스)
          팀 단위 체제 지시자 2개

모델      CatBoost 회귀 3개 + CatBoost 5클래스 분류 2개 (시드만 다름)
          로짓 공간에서 0.25 : 0.75 로 섞고 확률을 0.38~0.70 으로 클리핑

잔차 보정  정규리그 행만. 투수×타자 손 / 볼카운트 / 투수×볼카운트 / 주자 상태
          네 기준의 동결표를 각 행이 자기 키로 조회해 더함

평균 보정  학습 데이터로 추정한 2025 성공률 0.48051 에 맞춰 로짓에 상수 하나를 더함
```

## 실행

Python 3.11, CPU만 사용함. 아래 시간은 12스레드 기준이고 메모리는 16GB 이상 권장.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

DACON 에서 받은 `train.csv` 를 `data/` 에 넣음. 대회 데이터는 재배포하지 않으므로 저장소에 없음.

```bash
python derive_target.py     # 평균 보정 상수 계산. 약 30초, 0.48051 출력
python train.py             # 전체 학습. 약 3시간, output/submit.zip 생성
python train.py --fast      # 모델을 하나씩만 학습. 잔차표 재사용 시 약 35분
```

`train.py` 는 시간순 검증 예측(98분) → 잔차 보정표 생성 → 최종 모델 학습(71분) → 평균 보정과 행 독립성 검사(5분) 순으로 진행함. 검사는 같은 행을 한 개씩 넣거나 순서를 섞는 등 25가지 방식으로 입력해 결과가 완전히 같은지 확인하고, 하나라도 어긋나면 zip 을 만들지 않음.

`submission/` 은 1146.91 점을 받은 제출본과 같은 코드라 주석도 당시 그대로 둠. `submission/requirements.txt` 는 초반 LightGBM 계열부터 이어 쓰던 목록이라 지금 코드가 쓰지 않는 패키지도 들어 있음.

## 규정

- 대회는 2026년 9월 2일 종료됨. 규정 8-A 의 코드 공유 제한은 대회 기간에 한정되고, 8-B 는 대회 정보를 바탕으로 만든 소스 코드의 공개를 허용함
- 규정 7-B 에 따라 대회 데이터와 주최측 데이터 설명서는 포함하지 않음
- 보정에 쓰는 기준값은 전부 학습 데이터로 만들어 저장해 두고 각 행이 자기 값으로만 조회함
